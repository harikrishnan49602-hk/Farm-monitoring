# Farm-monitoring
This smart farm monitoring system uses an ESP32, DHT11, soil moisture sensor, and rain sensor to monitor farm conditions. Temperature, humidity, soil moisture, and rainfall values are sent to the Blynk dashboard through Wi-Fi. The LCD displays temperature, humidity, and watering status, helping farmers manage irrigation efficiently.

The Smart Farm Monitoring System uses an ESP32 to monitor soil moisture, temperature, humidity, and rainfall in real time. The DHT11 sensor measures temperature and humidity, while the soil moisture sensor checks the water content in the soil. The rain sensor detects rainfall conditions. The ESP32 processes the sensor readings and sends them to the Blynk IoT dashboard through Wi-Fi. The LCD displays the temperature, humidity, and soil watering status. When the soil moisture reading is below the set threshold, the system displays “No Need Water”; otherwise, it displays “Need Water.” This system helps farmers monitor field conditions remotely, reduce unnecessary watering, conserve water, and improve irrigation management.
